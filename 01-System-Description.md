# Sparkman Systems LLC - System Description

Sparkman Systems LLC is a fictional small business with approximately 25 employees.

The company uses:
- Windows laptops
- Microsoft 365
- A Windows file server
- Active Directory
- A VPN for remote access
- Company Wi-Fi
- A perimeter firewall

## System Boundary

The system boundary includes the company’s employee laptops, Active Directory environment, file server, Microsoft 365 services, VPN infrastructure, wireless network, and perimeter firewall.

## Information Types

Sparkman Systems LLC handles:
- Employee personnel information
- Internal company documents
- Customer contact information
- Business contracts
- Financial records
- Email communications
