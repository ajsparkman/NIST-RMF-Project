# IA-2 - Identification and Authentication Assessment

## Control

IA-2 - Identification and Authentication

## Purpose

The purpose of this control is to ensure that users are uniquely identified and authenticated before being granted access to company systems.

## Assessment Question

Does Sparkman Systems LLC require users to securely verify their identity before accessing company systems?

## Evidence Requested

To assess IA-2, the following evidence would be requested:

- Password policy
- Multi-factor authentication configuration
- VPN authentication settings
- Microsoft 365 sign-in settings
- Active Directory authentication settings
- Sample user account configuration

## Evidence Reviewed

The following fictional evidence was reviewed:

- All employees were assigned unique user accounts
- Microsoft 365 required multi-factor authentication
- VPN access required multi-factor authentication
- Active Directory required passwords meeting the company password policy
- Shared generic accounts were not permitted for normal user access

## Assessment Result

Status: Satisfied

## Finding

No significant deficiencies were identified during the assessment of user identification and authentication controls.

## Risk

No material risk was identified based on the evidence reviewed.

## Recommendation

Continue enforcing unique user accounts, password requirements, and multi-factor authentication for Microsoft 365 and VPN access.
